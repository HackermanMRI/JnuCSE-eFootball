# Assets

Replace these with your own files. Nothing here affects any calculation.

| Path | What it is |
|---|---|
| `logo.svg` | Site logo, shown in the header and used as the favicon. Replace this file, or point `logo` in `data/config.js` at a different one. Square works best. |
| `players/` | Player photos. Square, about 400x400. Name them after the player id, e.g. `mrinmoy.jpg`. A player with no photo shows their initials instead, so this is optional. |
| `news/` | News banners. Landscape, about 1200x500. |

If an image file is missing the site does not break — the logo falls back to a built-in mark, players fall back to initials, and a news banner simply does not appear.
